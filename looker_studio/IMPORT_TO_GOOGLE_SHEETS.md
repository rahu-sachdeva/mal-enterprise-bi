## Fastest way (recommended)

1. Go to https://drive.google.com  
2. **New → File upload** → select `Mal_Enterprise_BI_Full_Report.xlsx` from Downloads  
3. After upload, right-click the file → **Open with → Google Sheets**  
4. Charts and tabs open as a Google Sheet  
5. **Share → Anyone with the link → Viewer**  
6. Copy the new Sheet URL for the assessment (or replace contents of your existing Sheet — see below)  
7. Test in **incognito**

This usually preserves charts better than importing into an existing file.

## Load into your existing Sheet URL

1. Open your Sheet:  
   https://docs.google.com/spreadsheets/d/1ag8hwKSlCm_GwLQvL-EeB2gJeLRqImkE4VmvklMJERc/edit

3. Choose **Replace spreadsheet** (or **Insert new sheets** if you want to keep old tabs)  
4. If some Excel charts do not convert, recreate them quickly:
   - Select the chart source table on the tab  
   - **Insert → Chart** → choose Line/Bar as in the Excel layout  
5. Share: **Anyone with the link → Viewer**
